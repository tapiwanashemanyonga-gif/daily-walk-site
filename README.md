# Daily Walk website

Responsive public website for the Daily Walk Christian spiritual-growth project.

## Live site

- Public URL: https://daily-walk-site.onrender.com
- Homepage: `index.html`
- Privacy policy: `privacy.html`
- Brand assets: `daily-walk-logo.svg`, `favicon.svg`
- Organic launch and social campaign guide: `campaign-kit.md`
- Search indexing files: `robots.txt`, `sitemap.xml`

## Publishing

The site is maintained in this repository's `main` branch and deployed through the connected Render static-site service. A commit to `main` updates the source; it does not by itself prove that the public deployment has finished. Check the Render deployment status and open the public URL after each release.

## Android download readiness

The Daily Walk Android repository currently has a signed APK attached to a GitHub pre-release validation release. That build is not yet approved as the public download. Keep the homepage download section in its verification state until the team has checked the final release APK, its signature, installation and first launch, and any required app/privacy disclosures. Then update the download CTA to the verified release asset.

## Advertising and privacy

- Do not copy A1 FAMILY MEDIA ad tags or Smartlinks into Daily Walk.
- Keep Bible reading, prayer and devotional experiences free from unsuitable advertising.
- Only add an ad integration after the placement, categories, consent/privacy disclosures and Android implementation have been tested.
- Update the privacy policy whenever analytics, advertising, forms or other data-processing services are introduced.
- The website privacy policy covers the public website only; the Android app needs its own accurate privacy disclosures.
