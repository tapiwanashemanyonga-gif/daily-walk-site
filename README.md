# Daily Walk website

A lightweight, responsive landing page for the Daily Walk Christian spiritual-growth app.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to finish deployment. The expected URL is `https://tapiwanashemanyonga-gif.github.io/daily-walk-site/`; verify it opens before submitting it to Adsterra.

## Adsterra readiness
- This page currently contains no ad scripts, Smartlinks, or trackers.
- Do not submit the URL to Adsterra until GitHub Pages is live and publicly accessible.
- Keep adult ads disabled. Select only suitable non-Smartlink formats if Adsterra offers them for the approved site.
- Website JavaScript ad code does not automatically become a supported Android-native ad integration. Test any WebView experiment separately before modifying the app.
